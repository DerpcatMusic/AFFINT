# Native editor image

`affint-native.png` is an unmodified capture of AFFINT's own 1024×720 window on an
isolated X11 display at scale factor 1, 2026-10-12. The document is AFFINT's original
synthetic study, rendered from editable vector and raster sources. This image
contains no Affinity capture, vendor artwork or personal document. Original
artwork and icons are MIT licensed; the unmodified embedded font retains OFL 1.1.

The image illustrates the current early editor. It does not establish complete
interface or feature parity with another application.
