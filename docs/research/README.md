# Research reports

These independently worded reports distinguish verified behavior, source
observations, inference and unresolved questions. They are historical records;
their old launch or research instructions do not override [AGENTS.md](../../AGENTS.md).
Installed Affinity windows must not be opened or manipulated.

Raw proprietary binaries, decompiler output, resource dumps, scraped pages,
upstream source mirrors and local diagnostic artifacts are excluded from the
public repository. Private paths and evidence identifiers describe retained
local research, not public downloads. Public reports contain no proprietary
implementation or vendor artwork. Audited open-source dependencies retain their
own licenses; a reuse candidate is not an assertion that its code was adopted.

Current implementation coverage belongs in [the roadmap](../roadmap.md), and
measured retained-work coverage belongs in [the performance report](../performance/retained-work-01.md).
